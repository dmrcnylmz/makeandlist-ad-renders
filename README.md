# MakeAndList ad renders

Frame-exact HTML ad compositions for MakeAndList (`motion/ads/b*.html`), rendered on GitHub Actions: one job per ad,
9:16 and 4:5, original synthesised score, -14 LUFS / -1 dBTP QC. Screens are the real app with its demo workspace
(sample data) and the design-canvas boards; products are the owner's own examples.

Render: push to `main` (touching `motion/ads`) or run the workflow with `ads="b01 b02"`; download the `ad-*` artifacts.
