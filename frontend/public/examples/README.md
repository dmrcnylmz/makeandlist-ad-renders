# Actual production examples

These six unchanged PNGs are cover and page-3 previews from three owned generated products: Halloween coloring, dinosaur coloring and a Winter/Christmas word-search pack. They are not fixtures or generated marketing replacements. Original source checksums, PNG CRCs and absence of text/EXIF chunks were checked; all six images were visually inspected. Prior independent delivery reviews are PASS_WITH_NOTES, not a guarantee of physical print quality or every related category.

The public manifest intentionally contains no account/workspace/product/asset UUID, owner email, credit balance, provider receipts, storage keys or private signed URLs. Canonical product-to-asset provenance remains in a private handoff. Word Search has zero original illustrations and uses local puzzle layout: never label it original drawings. Cover artwork repeats an interior intentionally and is not another unique content unit.

Consume `/examples/manifest.json` after these assets enter a frontend deployment. This source commit alone does not publish or wire a gallery. A rendering integration should preserve aspect ratio, display the actual example title/type, and distinguish a same-family example from proof of all categories. Existing authenticated source asset routes remain tenant-bound; they must not become anonymous owner-asset proxies.
